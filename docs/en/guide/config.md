# Config

Key flags live in `/data/adb/certbridge/user.conf` (outside the module tree).

| Key | Meaning |
| --- | --- |
| `ui_lang` | `system` / `zh-CN` / `en` |
| `mount_mode` | `compatible` / `magic` |
| `tmpfs_style` | Path style for temp mounts |
| `experimental_14_system` | `auto` / `skip` on API 34+ |
| `quiet_prop` | Short module.prop description |

Use WebUI or `cb set …`.
