# FAQ

**Where to download?** GitHub Releases only.

**Which zip?** Prefer `*_arm64.zip`. Emulators use x86/x64. Lite skips OpenSSL.

**Certs not working?** Reboot after toggles. Avoid “umount module” on capture apps. Check Hide docs.

**Language?** WebUI follows system (zh / en); others fall back to English. More → Mount → Language.
