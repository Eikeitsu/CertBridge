# Features

CertBridge injects capture-tool CAs into the Android system trust store for Magisk / KernelSU / APatch.

- Boot-time merge of live system CA + enabled addons
- Reqable / ProxyPin sync; custom PEM / DER
- Compatible mount (default) or lite Magic Mount
- Optional hide assist and Zygisk filter
- WebUI + `cb` CLI + optional hot mount

See [Install](./install) to pick a zip.
