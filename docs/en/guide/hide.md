# Hide

Bind mounts put CAs into the system trust store. Capture apps and targets must **see** those mounts.

- Optional SuSFS / kernel `try_umount` assist (off by default)
- Optional Zygisk mountinfo/maps filter (custom install)
- Do **not** enable “umount module” on Reqable / targets while capturing

Details: Chinese docs remain the full reference; this page is a short EN overview.
