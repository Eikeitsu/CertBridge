# Install

Download from [GitHub Releases](https://github.com/Eikeitsu/CertBridge/releases).

| Zip                       | Who                              |
| ------------------------- | -------------------------------- |
| `*_arm64.zip`             | Most phones (default updateJson) |
| `*_arm32.zip`             | 32-bit ARM                       |
| `*_x86.zip` / `*_x64.zip` | Emulators                        |
| `*_lite.zip`              | Tiny; no OpenSSL                 |

Flash in your root manager → reboot → open WebUI or `cb status --live`.

Volume keys: **Vol+** = default, **Vol-** = custom. 20s timeout → default.
