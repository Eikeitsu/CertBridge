# WebUI 使用说明

证书桥 WebUI 在模块管理器中打开（KernelSU 管理器、MMRL、WebUI-X 等）。界面为 **React** 单页应用，底部四页：**概览 · 证书 · 日志 · 更多**。

## 打开方式

1. 安装时选择默认安装或自定义安装并勾选 **WebUI**  
2. 重启后在模块管理器进入 **证书桥 → WebUI**  
3. 需管理器提供 shell 桥接（普通浏览器无法执行模块命令）

若提示「未检测到 WebUI 桥接」，请换用支持模块 WebUI 的客户端。

## 概览

概览页展示当前信任状态与运行环境，适合快速确认「有没有挂上、要不要重启」。

| 区域 | 内容 |
| --- | --- |
| 统计卡片 | 已启用附加证书数、自定义证书数 |
| 状态徽章 | 与模块列表简介一致（✅运行正常 / ⏳待重启 / ⚠️异常 等） |
| 说明文案 | 正常时显示当前生效证书摘要；异常时显示可读诊断 |
| 运行详情 | Android 版本、Root 实现、APEX 注入、挂载模式、热挂载、模块版本 |
| 当前信任名单 | 已生效的 Reqable / ProxyPin / 自定义证书名称 |
| 快捷操作 | 重启、跳转证书页、临时证书（若已安装热挂载组件） |

### 刷新状态

点 **刷新状态** 会：

1. 尝试从已启用的 **Reqable / ProxyPin App** 同步最新 CA（指纹未变则跳过）  
2. 重新读取模块状态与自定义证书列表  

若有证书更新，会提示 **重启后生效**。

### 注入失败诊断

当注入异常时，概览会显示 **诊断卡片**（原因 + 建议），并提供 **查看日志** 入口。常见提示包括：

| 情况 | 说明 |
| --- | --- |
| 证书集合生成失败 | 未改动系统信任库，可查日志中 `generation` |
| 临时层 / bind 失败 | 可能与 `/data/local/tmp` 空间或权限有关 |
| 命名空间注入失败 | 建议重启后重试；目标 App 需强停再开 |
| 轻量叠层未生效 | KernelSU 等需确认 Magic Mount 是否正确 |
| 校验未通过 | init / Zygote 命名空间内证书与预期不一致 |

模块 **Action** 与列表简介也会同步显示相同诊断文案。

## 证书

### 抓包应用证书（Reqable / ProxyPin）

- 显示产品图标与当前证书名称（来自 App 导入或 ProxyPin 内置兜底）  
- **开关**：开启 / 关闭附加证书（**重启后生效**）  
- **详情**：点击 ℹ️ 查看主题、颁发者、有效期、指纹等  
- 副标题提示：  
  - 「已应用 / 已开启待重启 / 已关闭仍在生效」等状态  
  - 未检测到证书时提示先在 App 内生成  

开启开关前会尝试从 App 刷新；若无可用来源会拒绝开启。

### 自定义证书

- 上传 **PEM / DER**（按内容识别，不必改后缀）  
- 适用于 HttpCanary、ADGuard、Charles 等，或 App 未自动检测到时  
- 导入后 **重启生效**；可查看详情与删除  

### 临时免重启挂载

若安装时启用了热挂载组件，证书页底部会出现 **临时免重启挂载** 区域：

| 操作 | 说明 |
| --- | --- |
| 挂载用户证书 | 读取各用户「用户证书」并临时提升为系统信任 |
| 挂载存储卡证书 | 默认目录 `/sdcard/Documents/cacerts`，路径可改 |
| 挂载全部 | 用户区 + 存储卡合并 |
| 无痕卸载 | 仅撤销本次临时会话 |

临时挂载 **立即生效**，**重启后消失**，不改永久配置。详见 [配置说明 · 热挂载](/guide/config#临时免重启挂载热挂载)。

## 日志

- 查看 `data/install.log` 尾部（安装、开机注入、同步等）  
- **刷新** / **清空**（清空不影响证书配置）  
- 排查注入失败时，可搜索 `inject:`、`generation:`、`post-fs-data`、`service`

## 更多

### 外观

| 选项 | 说明 |
| --- | --- |
| 主题包 | **经典** / **Material** / **流体** 三套视觉风格 |
| 深浅色 | 跟随系统 / 浅色 / 深色 |
| 自定义外观 | 开启后可调强调色、莫奈取色、悬浮底栏、毛玻璃等 |
| 紧凑卡片 / 字号 | 阅读偏好，仅存本机浏览器 |

### 挂载模式

- **完整兼容**（默认）：运行时整库 bind，不依赖 Magic Mount 元模块  
- **轻量 Magic**：仅叠 addon 证书；Android 14+ 仍对 APEX 脚本注入  

切换后需 **重启**。详见 [配置说明 · 挂载模式](/guide/config#挂载模式)。

### 临时挂载路径

- **短路径**（默认）：`.fs0` / `.fs1`，降低 mountinfo 关键词特征  
- **传统路径**：`sys-ca-merge*` 旧路径，便于排障  

切换后需 **重启**。

### 关于

版本、系统信息、文档与开源链接、Reqable / ProxyPin 外链、打赏码等。

## 与 Action 的分工

| 入口 | 适合做什么 |
| --- | --- |
| **WebUI** | 改开关、导入证书、热挂载、看日志、调外观与挂载模式 |
| **Action** | 只读仪表盘：版本、状态、注入诊断、热挂载摘要、日志路径（约 10s 内完成） |

Action **不再**提供音量键热挂载菜单；临时挂载请用 WebUI。

## 常见问题（WebUI）

**刷新后提示「已从 App 更新 N 张证书」**  
表示 Reqable / ProxyPin 根证有变化，需重启后进入开机证书层。

**开关已关但显示「仍在生效」**  
旧挂载尚未卸除，重启后才会移除。

**WebUI 能打开但状态一直加载失败**  
检查管理器 WebUI 桥接；Action 中 `状态 CLI` 行可用于对比。

更多排障见 [常见问题](/guide/faq)。
