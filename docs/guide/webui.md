# WebUI 使用说明

WebUI 在模块管理器中打开（KernelSU、SukiSU、APatch 系、MMRL、WebUI-X 等）。底部导航：**首页 · 证书 · 日志 · 更多**；安装了**挂载隐藏协助**和/或 **Zygisk 过滤**时多一页 **隐藏**。

视觉为统一的 Trust Signal：外观可调浅色 / 深色 / 跟随系统与强调色。

## 打开方式

1. 安装时选择默认安装，或自定义并勾选 WebUI
2. 重启后进入 **证书桥 → WebUI**
3. 需要管理器提供 shell 桥接（普通浏览器不行）

若提示未检测到桥接，请换支持模块 WebUI 的客户端。

## 首页

只回答「信任是否生效」：

| 区域         | 内容                                         |
| ------------ | -------------------------------------------- |
| Status Stage | 大状态、生效证书摘要、刷新复核 / 重启提示    |
| 指标         | 已启用 / 自定义 / 基线数量                   |
| 内置 chips   | Reqable / ProxyPin 状态                      |
| 环境详情     | 折叠：设备、系统、Root、注入、挂载模式、版本 |

挂载与隐藏实况在 **「隐藏」** 页，见 [挂载隐藏](/guide/hide)。

### 刷新复核

1. 尝试从已启用的 Reqable / ProxyPin **同步最新 CA**（指纹未变则跳过）
2. **强制实测**注入（`status --live`）并回写缓存
3. 重新读取自定义列表

开机后若短暂「稳定中」，页面会静默复核；也可手动点刷新。

## 证书

| 区域   | 内容                                                        |
| ------ | ----------------------------------------------------------- |
| 内置源 | Reqable / ProxyPin 开关、详情（指纹、主体等，可复制）       |
| 自定义 | 上传 PEM / DER、导入预设路径、删除、详情                    |
| 热挂载 | 用户区 / 存储卡临时挂载与卸载（仅已装组件且 `hot_allow=1`） |

永久改动保存后通常需**重启**；热挂载立即生效、重启后消失。

## 日志

查看 `data/install.log` 与运行日志：级别过滤、搜索 `inject:` / `generation:` / `hide:` 等。注入失败时首页与日志会给出可读原因与建议。

---

## 隐藏

仅组件已装时出现。包含：

- 挂载与隐藏实况、分 Root 方案说明
- `hide_allow` / `zn_hide_allow`、白名单、立刻重登记
- 抓包检查清单（可关闭）
- **冷门实验**：`force_bind_capture`、`late_inject`、`boot_bind_zygote`、`boot_multi_apex`、`service_probe`

默认冷门项全关，优先痕迹最少；证书异常再开。详见 [挂载隐藏](/guide/hide)、[配置说明](/guide/config)。

## 热更新路径

跨安装器热更新短时文件可能在：

```text
/data/adb/certbridge/
```

平时可忽略；更新完成后会清理。
