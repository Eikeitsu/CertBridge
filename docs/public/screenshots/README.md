# WebUI 截图维护

文档与 README 引用本目录下的界面示意图：

| 文件                 | 对应页面 |
| -------------------- | -------- |
| `webui-overview.svg` | 首页     |
| `webui-certs.svg`    | 证书     |
| `webui-log.svg`      | 日志     |
| `webui-hide.svg`     | 隐藏     |
| `webui-more.svg`     | 更多     |

当前为结构示意 SVG。发版前可用真机截图替换（保持同名 `.png` 或 `.svg`，并同步文档中的扩展名）。

建议环境：

- KernelSU / MMRL 打开模块 WebUI
- 状态为「运行正常」，至少启用一张附加证书
- 隐藏页展示挂载实况（若已装组件）
- 宽度约 360–390px
