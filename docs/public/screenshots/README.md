# WebUI 截图维护

文档与 README 引用本目录下的界面示意图：

| 文件 | 对应页面 |
| --- | --- |
| `webui-overview.svg` | 概览 |
| `webui-certs.svg` | 证书 |
| `webui-log.svg` | 日志 |
| `webui-more.svg` | 更多 |

当前为 **结构示意 SVG**，便于文档站离线展示。发版前可用真机 WebUI 截图替换（保持同名 `.png` 或 `.svg`，并同步更新 `docs/guide/*.md` 中的扩展名）。

建议截图环境：

- KernelSU 管理器或 MMRL 打开模块 WebUI  
- 状态为「运行正常」且至少启用一张附加证书  
- 证书页展示 Reqable / ProxyPin 开关与热挂载区（若已安装）  
- 更多页展示外观与挂载模式区块  

分辨率建议宽度 360–390px，PNG 即可。
